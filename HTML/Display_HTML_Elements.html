HTML Elements Tutorial

The <h1> Element

The <h1> element is used to create the main heading of a webpage.

Syntax: 
<h1>Welcome to My Website</h1>
Output:

Welcome to My Website

The <p> Element

The <p> element is used to create paragraphs.

Syntax: 
<p>This is a paragraph.</p>
Output:

This is a paragraph.

The <img> Element

The <img> element is used to display images.
